# Projeto-juros-compostos
Descrição do Projeto: Simulador Financeiro  Ferramenta web para planejar e acompanhar metas financeiras. Simule cenários com valores iniciais e metas diárias. Acompanhe a performance em tempo real em uma tabela dinâmica, com cálculos automáticos e status visuais. Ideal para organização e análise de resultados.
